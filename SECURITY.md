# Signaler une vulnérabilité

Ne publie pas une vulnérabilité non corrigée dans une Issue ou une Discussion publique.

Utilise le [signalement privé de vulnérabilité GitHub](https://github.com/Mesrine67/fxmpOS/security/advisories/new). Indique la version ou le commit concerné, le système d’exploitation, l’impact, les étapes minimales de reproduction et une éventuelle mesure d’atténuation.

Ne joins pas de clé de signature, jeton, mot de passe, identifiant personnel ou fichier contenant ces données. Si un secret a été exposé, révoque-le ou fais-le tourner depuis son fournisseur sans le recopier dans le rapport.

FXMP OS publie des versions Windows 0.x avant sa première version 1.0; consulte la [page des releases](https://github.com/Mesrine67/fxmpOS/releases) pour les versions disponibles. Les rapports seront examinés par le mainteneur; aucun délai de réponse n’est garanti. La divulgation publique doit attendre une coordination avec le mainteneur et la disponibilité d’un correctif ou d’une mesure d’atténuation.
